# FVM 关卡编辑器（适配 FVM-Reborn-mod）

单文件网页编辑器：`index.html` + `data.js`（+ `thumbs/` 图标缩略图）。
数据由 `gen_data.ps1` 从工程里现抓，**不写死**任何卡片 / 敌人 / 地图 / 音乐 ID。

## 启动

| 方式 | 操作 |
| --- | --- |
| 双击启动器 | `tools\level_editor\关卡工坊.exe`（找不到就 `关卡设计.exe`，两个是同一份） |
| 直接开网页 | 双击 `tools\level_editor\index.html`，Edge / Chrome 均可 |

启动器优先用 exe 同目录、或上级目录 `tools\level_editor\` 里的 `index.html`，
这样卡片、敌人、龙柱图标才能按相对路径取到 `sprites\` 下的 png。
只有在找不到工程时，才退回内嵌副本（此时没有图片）。

`build.ps1` 用于重新编译启动器（需要 .NET Framework 4 的 csc）。
界面代码改了不用重编译，刷新页面即可；只改了 `data.js` 也一样。

## 页面 1：基础信息

对应关卡 json 的顶层字段。

- **版本号**：可以是数字 `1.2 / 1.4 / 1.5`，也可以是老格式字符串 `"1.1.0"`。
  引擎用 `is_real(version)` 判断，**字符串会走另一条分支**，所以这里保持原样，
  不要手动把 `1.1.0` 改成 `1.1`。
- **关卡时间**：`daytime` / `night`，决定引擎取哪套昼夜逻辑。
- **地图精灵**：下拉里是全部 27 个真实用过的 `spr_*`，选中右侧直接预览。
- **三段音乐**：先锋段 / 精英段 / BOSS 段，可点「试听」听 `sounds\` 里的 wav。
- **时间限制**：秒，`0` = 不限时。
- **第一波延迟 / 最短最长波长**：单位都是**帧**（60 帧 ≈ 1 秒）。
- **精英段波次**：从第几大波开始切精英段；`0` 或 `-1` 表示没有精英段
  （原版有 139 个关卡写的是 `0`，所以这里不强制 ≥1）。
- **BOSS 出现波次**：只用于界面提示，可以大于总波次（原版就有 `total_waves=2` 而 `boss_wave=4` 的关卡）。
- **敌人血量倍率**：`1` 原始血量，`2` 双倍（龙渊关卡多为 2）。
- **总波次**：改动会立即同步增删下面的波次列表。

点「进入地图信息 →」或顶栏第 2 个 tab 继续。

## 页面 2：地图信息

左栏是笔刷，中栏是网格，右栏是「本格信息」。

- **地形笔刷**：普通 / 水域 / 障碍。点格子涂，按住拖动连续涂。三个地形用格子底色区分
  （灰 = 普通，蓝 = 水域，棕 = 障碍），开着地图底图时也会叠一层半透明色，方便分辨。
- **水行判定**（重要）：引擎 `Create_0.gml:146` 只用**每行第 2 格**（索引 1）的 `type`
  判整行是水还是陆。所以编辑器里「本行设为水域 / 陆地」按钮会把整行写成同一个 type，
  和原版关卡习惯一致。左栏行号旁有 💧 标记的就是水行。
- **初始卡片笔刷**：可选工程里全部 207 张卡（普通卡 / 金卡 / 生肖卡 / 融合卡 / MOD 卡），
  按分类过滤 + 搜索名字或 ID。点格子放一张，再点一次移除，一格可叠多张。
- **地图物件笔刷**：障碍物、风洞、岩浆、海水、**龙柱 4 色**（懒惰/暴食/贪婪/傲慢）、岩浆轨道 ×2。
  放下后在格子上直接画出图标（图标已按 alpha 裁掉透明边，所以 56px 格子里也看得清）。
  放龙柱时如果格子是普通地形，会自动改成障碍——原版龙渊关卡就是 `type:"obstacle"` + `object:["ly_longzhu_1"]`。
- **右键** = 清空该格。**滚轮旁边的 − / +** 调格子大小（32–96px）。
- **显示地图底图**：把 `map_sprite` 按行列切成小图铺在格子下，方便对照原关卡。

## 页面 3：波次信息

左栏是老鼠系列（**美味岛 146 / 跨服系列 26 / 龙渊系列 18 / 灼热系列 18 / 感染 MOD 23**），
可搜索名字或 ID，每条显示图标、名字、ID、HP、水陆。

操作流程（和 2.10 版一致）：先在左栏点一只老鼠 → 再点右栏「行选择器」里的行号。

- **行 1–7**：把这只老鼠放到指定行；**随机行**写 `-1`；**每行各 1 人**批量铺满。
- 陆行只能放陆地敌人、水行只能放水域敌人（引擎 `Create_0.gml:317-319` 会强制改行），
  编辑器在提示里标了当前敌人是陆还是水。
- **大波列表**：显示每波子波数 / 敌人数，带「精英段」「BOSS」标记，可 ＋添加 / 复制 / 删除。
- **BOSS 波**：勾选 `boss_wave`，可选 BOSS 1 / BOSS 2 并各自设血量倍率。
  （`boss3` 字段引擎全工程没读过，编辑器只在保存时原样保留。）
- **子波**：每个大波下可加多个子波，子波 tab 上显示「子波 N · 敌人数」；
  「最短/最长波长」填 `-1` 表示继承关卡全局值（**只有 version ≥ 1.3 的关卡才会读这两个字段**）。
- 每个敌人条目可单独改行号、改 prosperity（刷怪权重）、删除。

## 保存与载入

- **保存 JSON**：下载 `<level_name>.json`。放进 `datafiles\level_data\` 下对应子目录
  （`camp` / `cross` / `floating` / `longyuan` / `tower` / `undersea` / `volcanic` 或根目录）
  就会被关卡选择器读到。
- **加载 JSON**：选一个已有 json 继续改。真实关卡文件末尾常带一个 `\u0000` 空字节，
  编辑器会自动清掉，直接拖进来就行。
- **校验**：检查未知卡片/敌人 ID、行号越界、音乐/地图精灵是否存在、水行放水域敌人、BOSS 波没选 BOSS 等。
- 编辑内容会自动存进浏览器 localStorage，误关页面不会丢；「新建关卡」才会清空。

## 数据重新生成

卡片 / 敌人 / 音乐 / 地图 / 物件的清单都是抓出来的，工程里加了新卡新怪之后跑：

```powershell
powershell -ExecutionPolicy Bypass -File tools\level_editor\gen_data.ps1
```

会重写 `data.js` 和 `thumbs\obj_*.png`。

数据来源：

| 内容 | 来源 |
| --- | --- |
| 卡片 207 张 | `scripts\slots_init\slots_init.gml`、`scripts\mod_slots_init\mod_slots_init.gml`，名字取自 `docs\全部卡片清单.md` |
| 敌人 231 条 | `enemy_init` / `mod_enemy_init` / `longyuan_enemy_init` / `zhuore_enemy_init` / `zhuore_boss_init` |
| 音乐 50 首 | `sounds\` 下非 `snd_` / `se_` 前缀的目录 |
| 地图精灵 27 个 | 扫 `datafiles\level_data\**\*.json` 里出现过的 `map_sprite` |
| 地图物件 10 个 | `scripts\map_object_init\map_object_init.gml` 的 `register_map_object` |

## 已知限制

- 龙柱只有 4 种有周期机制（`longzhu.gml` 的 `longzhu_apply_effect` 只处理
  cheng/lv/huang/lv2）。蓝/红/紫虽然引擎里有精灵，但没有效果，所以没放进按钮列表。
- 「跨服 / 龙渊 / 灼热 / 感染」是按 ID 前缀与注册文件分组，不是按关卡目录分组；
  关卡里能用的就是这 231 个 ID，列表里找不到说明工程里没有这个怪。
- 保存出来的 json 是标准 UTF-8、无 BOM、无尾部 NUL；引擎读没问题，和原文件的唯一差别就是少了那个尾字节。
