## 一、三种玩法分别用哪套概率

| 玩法 | `play_mode` | 入口函数 | 说明 |
|---|---|---|---|
| 经典 | 0 | 无抽卡 | 通关按关卡 `rewards` 发奖 |
| 抽卡 | 1 | `gacha_pick_random_reward()` | 见第二章 |

对比抽卡模式：金卡 15% → 40%（2.67 倍），融合 15% → 20%，生肖 29% → 25%，普通 40% → 10%。

## 四、随机礼盒（`play_mode = 3`）

`random_gift_pick_card()`（`gacha_random_card.gml:61-62`）用 `weights = [17, 35, 40, 5, 2, 1]`，**是真百分比**（合计正好 100，不像抽卡那样归一化）。

| 类别 | 概率 | 池内候选 |
|---|---|---|
| 金卡 | 17% | 38 张（39 张金卡去掉黑名单 `brahma`） |
| 生肖卡 | 35% | 66 张（68 张生肖去掉黑名单 `baibianshe`、`lihe`） |
| 普通卡 | 40% | 83 张（普通 74 + 融合 11，去掉黑名单 `magic_chicken`、`ice_cream`） |
| 普通鼠 | 5% | 全部非精英、非 BOSS 敌人 |
| 精英鼠 | 2% | `elite` 或 `ash_proof` 的敌人 |
| BOSS | 1% | 在 `global.boss_list` 里的敌人 |
| **合计** | **100%** | |

礼盒的卡片分池只有三档（`:35`）：`gacha_is_gold_card` → 金卡池，否则 `gacha_is_zodiac_card` → 生肖池，否则普通池。**没有 fusion 分支**，所以融合卡会落进普通池。

池内实际候选还会被 `has_card` 检查再削一轮（`:28-34`）：某个形态的 `obj == noone` 或 `get_plant_shape_data` 取不到，这张卡就被跳过。所以上表是按静态数据算的上限，运行时可能略少。

## 五、动态规则（会让实际概率偏离上表）

### 5.1 空池重分配

任何一类候选为空，它的权重就**整个消失**，池内权重按比例分给其它类（`:654-673`）。

举例：融合菜谱全部解锁后，fusion 的 15 点权重消失，抽卡模式变成 gold/zodiac/normal/weapon/gem 五类按 15/29/40/0.5/0.5（合计 85）分摊，金卡从 15% 升到 17.65%。

### 8.2 分类规则（2026-11-07 定稿）

`gacha_is_zodiac_card()` 现在是**默认生肖**，判定顺序：

1. 金卡 → gold 池（发进化凭证），最高优先级
2. 融合卡 → fusion 池（发初融菜谱）
3. 在 `_normal` 名单里 → 普通池
4. `gacha_is_map_unlock_card()` 命中 → 不进池
5. **其余一律生肖池** —— 新增卡片不用改函数，自动进生肖池

- 要让新卡进**普通池**：把 id 加进 `gacha_is_zodiac_card()` 的 `_normal` 数组
- 要让新卡**不进池**：把 id 加进 `gacha_is_map_unlock_card()` 的 `_map_only` 数组

### 8.3 关卡首通卡与本章的区别

`gacha_get_excluded_cards()` 另有 13 张「本体只能靠关卡首通拿」的卡：wooden_plate / wooden_cork / cotton_candy / sausage / oil_lamp / soda_bubble / tang_hu_lu / double_water_pipe / mixian / huagao / fushengcha / hongliukaochuan / chunsun。

它们与本章不是一回事：本章是**分类上完全不进池**，而 `gacha_get_excluded_cards()` 是**分类上在池里、但未拥有且不是本关奖励时跳过**。后 5 张（mixian / huagao / fushengcha / hongliukaochuan / chunsun）属于普通池 74 张，只是实际抽不到。
