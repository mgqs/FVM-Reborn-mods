## 五、分类说明

### 1. 卡片类别（品质 / 获取）
| 值 | 含义 | 判定 |
|---|---|---|
| 普通卡 | 普通卡（普卡） | 默认无标记 |
| 金卡 | 金卡 | 形态 0 `is_gold == 1`，或诸神商店 `gods_goods_map` 中的卡片；星级上限 18 |
| 生肖卡 | 生肖卡 | 非金卡且商店价 ≥ 80000 的卡片类商品（见 `gacha_is_zodiac_card`） |
| 融合卡 | 融合卡 | 形态 0 `is_fusion == 1`，或 id 属于 `lizi_god / youyu_god / ronghehaixing / ronghedan_god`；卡底用 `spr_slot_2` |

### 2. plant_type（占格 / 放置类型）
| 值 | 含义 |
|---|---|
| `normal` | 普通植物，占 1 格 |
| `lilypad` | 莲叶 / 花盆，只能放水上 |
| `coffee` | 咖啡壶 / 木塞类，可放障碍地形 |
| `shield_outer` | 护罩外层（瓜皮护罩） |
| `gridless` | 不占格（悬浮卡，如泡椒春笋） |
| `shegengbao` | 蛇羹煲，不占格的一次性回收卡 |

> `shield_inner` 仅作为绘制层级 / 护罩子对象出现，不是注册卡片的 plant_type。

### 3. feature_type（卡片特性）
| 值 | 含义 |
|---|---|
| `normal` | 无特殊特性 |
| `water` | 水生，只能种水上 |
| `amphi` | 两栖（水陆皆可） |
| `dwarf` | 矮小，不能种水上 |
| `low` | 低矮（咖啡杯等） |
| `upgrade` | 升级 / 替换类 |
| `bun` / `king_bun` | 包子类 / 国王包子类 |
| `tbun` / `king_tbun` | 三向包子类 / 国王三向包子类 |
| `lava` | 岩浆类（炎凰马） |
| `haiyang_obstacle` | 海洋女神悬浮形态，可放障碍、不占格 |
| `shegengbao` | 蛇羹煲 |

### 4. target_type（攻击目标类型）
| 值 | 可打到的敌人类型 |
|---|---|
| `normal` | 地面（除空中） |
| `air` | 地面 + 空中 |
| `air_only` | 仅空中 |
| `throw` | 地面 + 潜水鼠 |
| `track` | 地面 + 潜水 + 空中 |
| `pierce` | 地面 + 舞者 + 障碍 + 隐形 |
| `rotate` | 除潜水外全覆盖（含地鼠 / 隐形） |
| `d_fruit` | 同 rotate |
| `all` | 全部 |

> 敌人端 target_type：`normal / diver / air / dance / obstacle / underground / invisible`。

> 另有 `split`（本项目自定义值，如盖亚神使，`can_target_on` 未涵盖，按默认逻辑处理）。

### 5. target_card（底座 / 联动目标）
`none`（无）、`player`（玩家），或具体卡片 id。
