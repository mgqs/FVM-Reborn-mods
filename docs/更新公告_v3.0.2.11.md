## 新增：BOSS 随机音乐

设置 → **音频设置** → 第三行「BOSS 随机音乐」勾选开关。
打开后每次进 BOSS 波会从曲库里随机抽一首，不再是固定那一首。

**内置 10 首**（随游戏走，不用自己准备）：

| 曲目 | 曲目 |
|---|---|
| 周杰伦 - 晴天 | 周杰伦 - 花海 |
| 周杰伦 - 明明就 | 周杰伦 - 青花瓷 |
| 未知歌手 - 七里香 | 杨丞琳 - 雨爱 |
| 张芸京 - 偏爱 | 蔡健雅 - 红色高跟鞋 |
| 阿YueYue,刘兆宇 - 冬眠 | (猴叫司凤版)-泡泡心 |

**想加自己的歌**：把 `.ogg` 文件丢进
`%LOCALAPPDATA%\FVM_Reborn_makk\boss_music\`
下次进 BOSS 波就会一起参与随机，放进去就能用，不用改配置。

- 精英波不受影响，仍用关卡原曲
- 没有 BOSS 的关卡不触发
- 曲库为空或文件损坏时自动回退原版 BOSS 音乐

## 手感：碰撞判定重做

**大体型老鼠的命中判定不再「提前」了。**
巨人鼠、球迷鼠这类怪以前是用精灵框直接判，挥爪换帧时判定框会突然横向拉长 40 多像素，导致子弹「还没打到就命中」。现在改成一张 **564 条固定判定框表**，按站立姿态的真实像素轮廓算，换帧不影响。

**同一行挤太多怪时也不再叠成一列跑到地图外面。** 现在超过 5 只会在出生点按像素错开，排队更自然。
