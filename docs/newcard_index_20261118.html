七、已经定死的口径

  • 星级：17 档（0~16），Max/Ultra 不注册（表内留空）。
  • 秒杀：不防爆 + 非精英 → 直接秒；其余吃「攻击力 × 倍率」。
  • 7 段递增：1/1.2/1.4/1.6/1.8/2/2.5，第 8 次起 3 倍；结界每次刷新清零。
  • 凭证：按雷电长棍面包高 2~4 层、威望 1.5~2 倍。
  • 缺失值：阴阳蛇 体力 50 / 冷却 7 秒；商城价 95000 / 105000。
  • 二转同格唯一：结界马是 gridless 悬浮卡，但同格只能放一张 —— 走 place_mutex_class 登记 jiejiema → "jiejiema_self"（比 gridless 分支更早判）。
  • 结界特效图层：压在卡片之下 —— depth = -10 - row_min*45 + 1 （卡片是 -10-45*row-5*col-层偏移，depth 越小越靠前）。
  • 雾只在连线范围内：多边形内部用 凸包三角扇 + 纹理 uv 画 （jiejiema_draw_fog_fan），几何就是多边形，超出连线的部分不会被画出来， 不再按包围盒拉伸成方框；多边形模式也不再画逐格方块。
  • 阴阳蛇出弹帧：攻击动画播到素材第 18 帧（image_index 17）才发弹 —— 16 帧低头蓄力、17 帧抬头张嘴、18 帧甩头吐出（差分峰值 2960 px）。 发弹后才把攻击段剩余帧补进 yy_anim_hold，整体周期不变、只是出弹晚半拍。
  • 阴阳蛇过火：火星子弹换成 spr_fire_bullet（4 帧火苗、1.8 倍）。 换贴图不归 bullet_hazard_fire 管（它只改倍率 / 尺寸）， 由子弹自己的 Step 写；融盆二转的冰弹（brazier_list 带 -9999）要让路。

八、结界雾是怎么裁到连线里的

多边形内部的雾不再用 draw_sprite_ext 按顶点包围盒拉伸，改成 draw_primitive_begin_texture(pr_trianglefan) + 逐顶点 uv（jiejiema_draw_fog_fan）。 几何本身就是凸包，所以「超出连线的部分」根本不会被画出来 —— 不需要 surface / stencil。
