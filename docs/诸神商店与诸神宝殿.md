## 一、系统结构

诸神相关只有一个入口，两个子界面：

```
地图/主菜单 → [诸神宝殿按钮 obj_gods_hall_enter]（常驻，无解锁门槛）
        │
        ├── 许愿机 ×3（obj_gods_hall_wish）  单抽 / 5 连 / 50 连 → 花金币
        │        └── 产出：金币 / 神谕之石 / 香料 / 强化水晶 / 4级四叶草
        │
        └── [兑换商店 obj_gods_store_enter] → 诸神商店（obj_gods_store_bg）
                 └── 花「神谕之石」买：神使卡本体 / 转职凭证 / 融合菜谱
```

**货币闭环**：金币 →（诸神宝殿抽奖）→ 神谕之石 →（诸神商店）→ 神使 / 凭证 / 食谱。
神谕之石**唯一来源就是诸神宝殿**，游戏里没有第二种获取途径。

### 2.3 保底池（每 50 抽触发一次）

`wish_count >= 50` 时改走保底池，且**按 `pity_count` 奇偶两档轮换**：

- **偶数档**（`pity_count % 2 == 0`）：先 roll 100
  - 60% → 4 级四叶草 ×25
  - 20% → 高级强化水晶 ×25
  - 20% → 再 roll 一次 100：60% 神谕之石 ×5 / 20% 神谕之石 ×10 / 20% 神谕之石 ×25
  - 即 **80% 空保底（只给四叶草/水晶），20% 给石（均值 10 石）**
- **奇数档**：**必出神谕之石** —— 60% ×5 / 20% ×10 / 20% ×25（均值 10 石）

结算规则：

- 抽到**神谕之石** → `wish_count` 归零（软重置），若本次是保底则 `pity_count++`。
- 抽到**四叶草 / 高级水晶**且是保底 → `wish_count` 归零、`pity_count++`（所以偶数档空保底也会推进到奇数档）。
- 其余（金币 / 香料 / 水晶）→ `wish_count++`。
- UI 在 `wish_count >= 40` 时用绿字提示进度，并显示「下次：四叶草/水晶/神谕之石」或「下次：神谕之石」。

### 2.5 抽卡模式：已与普通模式完全一致（2026-10-27 改）

旧版里 `is_eternal_gacha_mode()`（星际抽卡 / 欧皇抽卡）有三处特判，现已全部删除：

| 位置 | 旧行为 | 现行为 |
|---|---|---|
| `gods_hall_get_random_reward()` | 剔除神谕之石、香料区间放宽 | 与普通池同一张表，**出石** |
| `gods_hall_get_guarantee_reward()` | 只出 50% 四叶草 ×25 / 50% 高水 ×25 | 与普通保底同表（奇偶两档轮换，奇数档必出石） |
| `obj_gods_store_enter/{Mouse_4,Draw_0}` | 提示「抽卡模式无法使用兑换商店」+ 图标置灰 | 正常进店，无置灰 |

→ 现在**任何模式**下诸神宝殿 / 诸神商店口径一致：抽石 → 买神使 / 凭证 / 食谱。

## 三、诸神商店：货架规则

### 3.1 两个页签

| 页签 | 内容 | 商品数 | 实际页数 |
|---|---|---|---|
| ① 神使 | `type == "card"`（含 9 张融合菜本体，卖的是本体菜谱道具） | 48 件 | 3 页（16/页） |
| ② 凭证 | `type == "shape"` + 融合深度/灵魂食谱（`type == "recipe"`） | 132 件 | 9 页 |

- 但 `current_max_page` 在 `Create_0` 里**写死为 10**，所以页签①第 4–10 页、页签②第 10 页都是空白页（可翻、无货）。这是待修的小问题。
- 排序：融合卡(0) → 金卡(1) → 普卡(2)；档内按卡片首次出现顺序，同一张卡的 1/2/3 转相邻（`is_gold` 直接读形态 0，不走 `gacha_is_gold_card()`，否则全是金卡等于没排）。
- 顶部右上角常驻显示持有神谕之石数量。

### 3.2 购买条件

| 商品类型 | 条件 | 已满足时的表现 |
|---|---|---|
| 神使/神格卡本体 | 未解锁 + 前置卡满足（`fusion_prereq_met(id, 2)`，**前置要二转**） | 置灰 + 售罄遮罩 |
| 同上，例外① | 命运女神 `clotho`（`prereq_body_only`）→ 前置**有本体即可** | 提示文案不带「二转」 |
| 同上，例外② | 前置全是只有 0 转的卡（幻幻鸡 / 蓝莓塔）→ 按「该卡自己的最大形态」判定 | 提示文案不带「二转」 |
| 转职凭证 | 本体已解锁 **且** `max_shape >= target_shape - 1`（必须逐级买） | 置灰 + 售罄 |
| 融合食谱 | 背包里**没有**这本食谱道具（`has_fusion_recipe` 按数量 >0 判定，用掉后可再买） | 置灰 + 售罄 |

- 不足条件时按钮显示红字提示：`需先拥有[前置卡名]二转才能兑换！`
- 购买走确认弹窗：确认后 `add_material_amount("oracle_stone", -cost)` 再 `unlock_card()` / `upgrade_card_shape()` / 发食谱道具。
- 卡本体买下即 0 转解锁（`unlock_card(id, 0, 0, max_skill_level)`），**不含转数**，转数另买凭证。

### 3.3 价格分布

## 五、玩法要点（实战口径）

1. **神使是「卡」不是道具**：买下后进卡组，0 转形态即可上场；三档凭证分别是它的三转（shape 1）/ 四转（shape 2）/ 终转（shape 3）；部分新神只做到四转（神农氏、魔导士软糖、真·花火龙只有前两档）。
2. **买本体前必须先练前置**：前置卡一般要求二转（`max_shape >= 2`），所以「抽到前置 → 在魔塔/营地练到二转 → 回商店买神使」是标准路径。命运女神（克洛托）是唯一例外，前置创造神（梵天）只要有本体。
3. **凭证逐级解锁**：有三转才能买四转（`max_shape >= target_shape - 1`），不能跳级；且用 `max_shape` 判定，降转不会让你重买。
4. **融合菜本体在页签①、深度/灵魂食谱在页签②**：本体格卖的是「本体菜谱道具」（`spr_fusion_recipe0` + 卡面底色），不是卡本身；卡片要通过融合台用菜谱 + 材料做出来。
5. **食谱可回购**：只要背包里那本已经用掉（数量 0），就还能再买一本，所以可以囤不同形态的食谱交替用。
6. **各模式口径统一**：抽卡模式（星际 / 欧皇）也能抽到神谕之石、也能进兑换商店，与普通模式无差异。
7. **排序与分页**：融合卡优先，其后金卡、普卡；同一张卡的转职凭证连排，方便一次买齐。
