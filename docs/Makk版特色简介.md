# 《美食大战老鼠：重生MAKK》特色简介

---

## 二、标准版（约 300 字，推荐用于商店页 / README 顶部）

《美食大战老鼠：重生》是一款基于 GameMaker 引擎重新编写的美食大战老鼠同人游戏。

它没有走"高清重制 + 加法堆料"的老路，而是先把原作里最别扭的地方一个个拆掉重做：抽卡面板式的手感、繁琐的操作路径、被数值掩盖的战术深度。在这里，卡片回到"一格一位、站位即策略"的塔防本质，175 张卡、517 个形态按 12 个大类三级归档，增幅卡按分类生效而不是无脑叠倍率；每张卡都有本体、一转、二转（神使专属的终转形态更进一步）三条养成线，搭配 31 条食神谱、18 把武器、181 套装扮，可以组出真正属于自己的卡组。

关卡侧同样是重写的规模：13 座主题岛屿、35 层魔塔、浮空与海底、营地与跨服，以及独立机制的"龙渊"区域；169 种敌人、47 个 BOSS，6 档难度（美味→不朽）× 4 种玩法模式，从休闲通关到极限构筑都有落点。

游戏还开放了外部卡片 Mod 接口：一个 ZIP、一份 JSON、一段 Lua，就能把自己设计的卡片塞进游戏，与其他 Mod 共存，关掉也不会丢进度。

## 三、详细特色（分点版，用于介绍页长文）

### 1. 是"重写"，不是"移植"

整部游戏以 GameMaker 重新实现，不是给老客户端打补丁。底层重写带来的是：可以自由修改的数值模型、可插拔的卡片注册表、真正意义上的 Mod 支持——这些都是原版架构给不了的空间。设计目标写得很直白：**回归塔防初衷，优化不合理的游戏体验**。

### 2. 卡片是核心，而且深得离谱

| 维度 | 数量 |
|---|---|
| 卡片总数 | **175 张** |
| 卡片形态（含转职） | **517 个** |
| 原版卡 / MOD 卡 | 79 / 96 |
| 普通卡 | 120 |
| 金卡（神使） | 39 |
| 生肖卡 | 12 |
| 融合卡 | 4 |

- **转职不是换皮**：从本体到一转、二转，很多卡是机制级别的变化——范围从 3×3 扩到 5×5、攻击从单体变穿透、死亡后追加爆炸、甚至改变攻击目标类型。金卡神使还拥有三转、四转、终转等更强形态。
- **十二大类三级分类**：直射、投掷、多向、增幅、产能、辅助、专业防空、喷壶、追踪、非远程、灰烬、防御。每一张卡都有明确归类，也决定了它能吃到哪些增幅。
- **增幅按分类生效**：音盒马、浮生茶只强化"固定轨迹类"，炎焱兔只喂产能卡，海洋女神只增益喷壶与附加类。**同类增幅取最高、不叠加**——这就逼着你思考站位与搭配，而不是无脑铺满。
- **卡与卡之间有联动**：御风马遇到排风扇、幸运草扇、旋风牛会变成三行大风；子弹穿过火盆、金牛、火神会被点燃增伤，穿过布丁、水神会反弹。塔防玩出了组合拳。

### 3. 六档难度 × 四种玩法，一个游戏四种性格

- **难度**：美味级 → 火山级 → 浮空级 → 星际级 → 永恒级 → 不朽级，逐档加码的不只是血量，还有出怪节奏与精英配置。
- **玩法模式**：
  - **经典版**：按部就班解锁，最纯粹的推进体验。
  - **抽卡版**：用抽卡获取卡片与转职，适合喜欢养成的玩家。
  - **欧皇版**：抽卡规则更极端，赌的就是那一发。
  - **随机礼盒**：开局给你一个礼盒和几张基础卡，场上能开出什么全看运气——肉鸽味最重的一档。

同一张地图，换一个模式就是完全不同的解法。

### 4. 关卡量：13 座岛屿 + 35 层魔塔 + 独立机制区域

- **13 座主题岛屿**：美味、沙拉（陆/水）、曲奇、慕斯、香槟（陆/水）、布丁（日/夜）、可可（日/夜）、咖喱（日/夜）、火山、浮空、海底……每个区域都有专属地形规则（水域、岩浆、移动板块、夜间魂体系）。
- **魔塔 35 层、70 个正关**：逐层解锁的挑战模式，通关奖励直接发放卡片本体与转职材料。未解锁的楼层也能点进去预览。
- **龙渊（6 关）**：整套独立机制的终盘内容。核心是"龙柱"——橙柱催眠/清醒、绿柱摧毁/保护、黄柱火苗上限/返还、青绿柱青苹果/红苹果，桥头米线这类卡就是围绕龙柱设计的。BOSS 采用独立状态机与技能权重演出：游神、马头牛头、谛听、无常、孟婆，多 BOSS 关卡必须逐个击破才会推进。
- **浮空、海底、营地、跨服商店**：区域专属敌人、限定商品与形态卡，构成了长线收集的骨架。

### 5. 敌人和 BOSS 不是换个颜色

**169 种敌人、47 个 BOSS**，按目标类型严格分层：普通地面、潜水、空中、舞者、障碍、地下、隐形。你的卡组打不打得到它，取决于 `target_type`，而不是数值高低——

- 地精鼠在地下时只有能攻击 `underground` 的伤害才生效；
- 魂体系在夜间才转化，普通伤害只有 10%；
- 潜水鼠要投掷或追踪类才够得着；
- 隐形单位需要穿透类或特定显形效果。

这就是"选卡"真正有意义的原因。

### 6. 养成不止一条线

- **星级**：合成屋最高强化到 16 星，金卡还能由 Clotho 临时拉到 17、18 星。
- **转职**：本体 → 一转 → 二转，金卡更进一步。
- **技能**：每张卡的技能等级单独影响冷却、攻击间隔等关键参数。
- **食神谱（31 条）**：全局构筑加成，例如"南翔小笼包"让所有包子类卡片生命值变为 10 倍。按稀有度分档装备，是卡组之外的第二层构筑。
- **武器 18 把 / 时装 181 套**：外观与实战兼顾，不是纯皮肤。

### 7. 外部 Mod：这是它和多数同人塔防最不一样的地方

游戏内置完整的卡片 Mod 接口，做一个包只需要三个文件：

```
manifest.json   声明包名与卡片列表
card.json       卡片数值、动画帧、子弹、目标类型
logic.lua       行为脚本（索敌、发射、伤害、定时器）
+ images/*.png  图标、待机、子弹帧
```

打包成 `.fvmmod`（本质是 ZIP）丢进 Mod 目录即可导入，**导入、开关、删除在重启后生效，关闭 Mod 后卡片进度依然保留，重装同 ID 的包就能恢复**。Lua 侧提供 `on_create / on_step / on_timer / on_animation_event / on_animation_end / on_hit / on_destroy` 七个回调，以及 `api.shoot / damage / heal / produce / animate / timer / remove / log` 八条命令；子弹可以配置命中上限、穿透、反弹来源（布丁/水神）、增伤来源（火盆/金牛/火神）、灼烧概率与阵营筛选。

对作者来说，这是一套能真正做出"新卡"而非"换图卡"的接口。

### 8. 那些被顺手修掉的体验细节

- 选卡界面可以**鼠标右键退出**，结算界面可以**左键直接继续**；
- 魔塔蛋糕会**记住上次翻到第几页**；
- 未解锁的魔塔关卡也能点进去**预览**；
- 加载中不再能误点 UI；
- 大量贴图高清化，卡牌动画与战斗特效重绘。

看起来都是小事，但累积起来就是"这游戏能一直玩下去"和"玩两关就关掉"的差别。
