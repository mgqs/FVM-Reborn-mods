## 二、新增三把武器

### 海神镖枪（重制）

原版是「蓄力打一发」，现在是**连续齐射 + 可溅射**。

- 基础攻速 90 → 随等级 120 递减到 60
- 弹型随等级进化：初始是关东煮弹，4 级后变成海神三叉戟弹（共 4 种外观）
- 装 4 颗宝石后能一次打出 2～7 发，每发都带追踪

| 宝石 | 效果 |
|---|---|
| 魔影圣衣 | 子弹溅射，周围敌人一起吃伤害 |
| 魔影蛮力 | 加攻击力 |
| 魔影超刃 | 加连发数量（2 → 7） |
| 魔影迅疾 | 缩短冷却 |

**售价：200000 金币**（原 80000）

---

### 诸神之盾（新增）

副武器槽，+500 生命值。装宝石后是一台**全自动范围机器**。

| 宝石 | 效果 |
|---|---|
| 光能之源 | 周期性向周围喷火 |
| 撕裂之源 | 每 2.5 秒对周围 3×3 / 5×5 格敌人造成按最大生命值百分比 + 固定值的伤害 |
| 永恒之源 | 周围 3×3 卡牌攻击力 +5%～40%，5×5 用较低档位 |
| 生命之源 | 周围 5×5 卡牌最大生命值 +15%～100% |

**售价：200000 金币**

---

### 死神镰刀（新增）

超级武器槽。攻 200，冷却 900。

挥出一把旋转镰刀，沿 **O 形轨迹**横扫全场一圈后返回，**全程穿透**，路上每个敌人只吃一次。

装齐宝石后一次最多甩出 **4 把**，外观随等级变 3 种（普通 / 加长 / 双刃）。

| 宝石 | 效果 |
|---|---|
| 死神一击 | 加攻击力 |
| 死神收割 | 缩短冷却（900 → 342） |
| 死神苏醒 | 加镰刀数量（1 → 4） |
| 死神意志 | 换镰刀外观 + 附加伤害 |

**售价：200000 金币**

## 七、武器修复

- **死神镰刀打不到人** —— 它的命中判定沿用了引擎原生的碰撞事件，而本项目的子弹全部走手动扫描。已改成标准流程，现在能正常命中、正常穿透
- **海神镖枪一发都打不出来** —— 初始化时漏了两个计数器，进图就报错退出
- **死神镰刀子弹打完崩溃** —— 销毁时清理了没创建过的数据
- **死神镰刀挥砍末尾闪一下站姿** —— 动画分段多算了一帧，指向了不存在的第 35 帧
- **诸神之盾的宝石图标不显示** —— 装备界面判断「有没有图标对象」，4 颗宝石原本没绑定对象，等于永远画不出来
- **三把武器的精灵帧顺序错乱** —— 导入时按文件名文本排序（`_10` 排在 `_2` 前面），10 帧以上的动画全部错位，已按数字顺序重排
