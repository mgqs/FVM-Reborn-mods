# 跨服（变异）僵尸鼠精灵帧映射

## 一、问题

`spr_kuafu_armour` / `spr_kuafu_panda` / `spr_kuafu_wrestler` 三只跨服 BOSS 鼠的贴图取错了帧段：
背上本该驮着一只小老鼠（小熊猫 / 小装甲鼠 / 小摔跤手），实际游戏里背上一直是**空的**。

原因：上一轮移植时，主序列直接拿了 AS3 时间轴里 **「已扔出小老鼠」** 的那几段（`正常行走 / 受伤行走 / 正常砸东西 / 受伤砸东西`），
而 `_throw` 精灵又重复取了同一批空背帧，导致「带小老鼠」的段与「扔小老鼠」的段整体丢失。

## 五、执行脚本

`tools/fix_kuafu.py`（可复用）：

1. 读项目精灵 .yy（去尾逗号 → json）拿 `frames[].name` 顺序；
2. 读源目录 `1.png..204.png`；
3. 按上表把源帧覆盖写入 `sprites/<名>/layers/<frameGuid>/<layerGuid>.png`（保持目录与文件名不变，帧数与 .yy 一帧不改）；
4. 覆盖前整目录备份到 `.workbuddy/backup/kuafu_fix_20261105/`。

## 六、第三态：扔出后的空背精灵

扔出小老鼠后背上必须是空的，因此新增三个 100 帧精灵：

| 新精灵 | 源帧（1-based） |
|---|---|
| `spr_kuafu_armour_empty` | 41..61 / 62..82 / 119..136 / 137..154 / 183..204 |
| `spr_kuafu_panda_empty` | 同上（熊猫僵尸鼠 DefineSprite_78） |
| `spr_kuafu_wrestler_empty` | 同上（摔跤手僵尸鼠 DefineSprite_77） |

即：移动 正常 / 移动 受伤 / 攻击 正常 / 攻击 受伤 / 死亡，全部取标签里**不带小老鼠**的那四段 + 死亡段，索引位置与主序列一一对齐（21/21/18/18/22）。

生成方式（`tools/make_kuafu_empty.py`）：以现有主精灵 `.yy` 为模板复制，重新生成全部 frame GUID、layer GUID、keyframe id，同步改写 `frame.name`、`layers[0].name`、`sequence.tracks[0].keyframes.Keyframes[i].Channels.0.Id.{name,path}` 与 `name/%Name`，然后按上表把源帧写入 `layers/<新frameGuid>/<新layerGuid>.png`。

注册：`.yyp` 的 `resources` 数组加三条
`{"id":{"name":"spr_kuafu_<x>_empty","path":"sprites/spr_kuafu_<x>_empty/spr_kuafu_<x>_empty.yy",},},`
（该分组靠 `.yyp` 的 `folders` 登记 + 资源自身 `parent` 归属，`folders/精灵/Enemy/kuafu/mengyantiankong/xiaoguai/*.yy` 的 `listItems` 本为空，无需改动。）

## 七、Step_0 改造

`objects/obj_kuafu_{armour,panda,wrestler}/Step_0.gml` 两处 `sprite_index` 赋值改为按 `throwed` 二选一：

- 死亡分支（`hp <= 0 && state != ENEMY_STATE.DEAD`）
- APPEAR 收尾（`timer >= 14 * flash_speed - 1`，即扔完落回 NORMAL）

```gml
if throwed {
	sprite_index = spr_kuafu_armour_empty
} else {
	sprite_index = spr_kuafu_armour
}
```

`throwed` 在三个对象的 `Create_0.gml` 第 15 行初始化为 `false`，由 `Step_0` 第 16 行区域置 `true`（`grid_col > 4` 且血量低于 `maxhp * hurt_rate` 时进入 APPEAR）。全程只触发一次，不会反复切换。

## 八、复现与回滚

- 重切帧：`python tools/fix_kuafu.py`（主 + `_throw`）
- 重建空背三态：`python tools/make_kuafu_empty.py`（幂等，会先删目标目录）
- 备份：`.workbuddy/backup/kuafu_fix_20261105/`（6 个精灵原目录、3 个 Step_0 原件、改前 `.yyp`）
